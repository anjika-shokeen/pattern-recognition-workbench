# PRWB: End-to-End Pattern Recognition Workbench

A modular Python workbench that integrates **feature extraction, statistical analysis, classification, clustering and performance evaluation** behind one scikit-learn-compatible interface.
Mini project for the *Pattern Recognition* course (B.Tech, Computer Science and Engineering), by **Saksham Bakshi** and **Anjika Shokeen**.

Most core algorithms are written from scratch in NumPy and validated by an automated test-suite against scikit-learn / scikit-image / SciPy:

| Stage | Package | Implemented from scratch |
|---|---|---|
| Pre-processing | `prwb.preprocess` | standardiser, geometric normalisation |
| Feature extraction | `prwb.features` | HOG, LBP (default / u2 / riu2), GLCM (Haralick), Hu moments, zoning, projection profiles; signal: time-domain, Hjorth, spectral, auto-correlation; PCA, Fisher LDA; Fisher score, mRMR, correlation pruning |
| Statistical analysis | `prwb.stats` | normality, ANOVA / Kruskal-Wallis with FDR, effect sizes, correlation, Bhattacharyya distance, Mahalanobis outliers |
| Classification | `prwb.classifiers` | minimum-distance, k-NN, Gaussian Bayes (QDA/LDA/naive), Parzen window, softmax regression, MLP (backprop, Adam, dropout) + library models for comparison |
| Clustering | `prwb.clustering` | k-means++, EM for Gaussian mixtures, fuzzy c-means, gap statistic + hierarchical / spectral / DBSCAN / HDBSCAN for comparison |
| Evaluation | `prwb.evaluation` | confusion-matrix metrics, calibration (ECE), bootstrap CIs, McNemar, corrected resampled t-test, Friedman-Nemenyi, clustering indices |

Data sets: handwritten digits (images), synthetic waveforms (signals), wine and breast-cancer (tabular). All are generated or bundled, so **no download is needed**.

## Install

```bash
pip install -r requirements.txt
pip install -e .
```

## Use

```bash
python -m prwb datasets                                       # list data sets
python -m prwb features -d digits -f hog+lbp                  # extract descriptors
python -m prwb stats    -d wine   -f raw --top 10             # statistical analysis
python -m prwb classify -d digits -f hog+lbp -c SVM-RBF --folds 5
python -m prwb cluster  -d digits -f hog+lbp -a Agglomerative-Ward
python -m prwb train && python -m prwb predict some_digit.png  # deployable digit recogniser
streamlit run app/streamlit_app.py                            # interactive dashboard
```

Reproduce the whole study (figures and tables in `results/`):

```bash
python scripts/run_experiments.py --quick --out results_quick   # about 2 minutes
python scripts/run_experiments.py --config configs/default.yaml # full protocol, about 25 minutes
python notebooks/make_notebook.py                               # build the demo notebook
python -m pytest                                                # test-suite
```

Python API:

```python
from prwb import datasets
from prwb.features.builder import build_features   # see notebooks/ for complete examples
ds = datasets.load_dataset("digits")
```

## Layout

```
prwb/            package (datasets, preprocess, features, stats, classifiers, clustering, evaluation, pipeline, cli)
app/             Streamlit dashboard
scripts/         run_experiments.py: the full, scripted experimental protocol
configs/         experiment configuration (YAML)
tests/           pytest suite
notebooks/       demo notebook (generated by make_notebook.py)
results/         figures, CSV tables and JSON summary produced by the study
docs/            screenshots of the CLI and the dashboard
report/          sources of the project report
```
